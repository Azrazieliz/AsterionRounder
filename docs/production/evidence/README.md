# Evidence handling — Rounder

Keep **non-private, minimal** engineering records and links here when needed: commit SHA, GitHub Actions run IDs, release version, verdict scope, anonymized test outcomes.

- Do **not** commit private media, screenshots of personal content, card files, cloud tokens, local passwords, keystore/certificate private bytes, phone serial numbers or PC user paths.
- Cite GitHub release artifacts and PR discussion where existing; avoid copying redundant logs or binaries.
- A successful build is not a passed emulator run. A real signed APK does not automatically prove 3D rendering.
- Date every observation, distinguish actual device evidence from source assertions and record an owner verdict only from an explicit owner test/report.
